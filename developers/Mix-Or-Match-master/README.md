# Mix-Or-Match

A Halloween-themed memory card matching game built with vanilla JavaScript.

## How to Play

1. Open `index.html` in your browser.
2. Click anywhere to start the game.
3. Flip cards by clicking them — match all pairs before the timer runs out.
4. Win by matching every pair; run out of time and it's Game Over.

## Features

- 100-second countdown timer
- Flip counter to track your moves
- Creepy background music and sound effects (flip, match, victory, game over)
- Click to restart after a win or loss

## Files

| File | Purpose |
|------|---------|
| `index.html` | Game markup |
| `styles.css` | Styling and card animations |
| `script.js` | Game logic and audio controller |
| `Assets/` | Images and audio files |

## Running Locally

No build step needed — just open `index.html` in any modern browser.
